# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported |
| :--- | :--- |
| `main` (latest) | :white_check_mark: |
| Older commits | :x: |

## Reporting a Vulnerability

We take the security of Bilge AI seriously. If you believe you have discovered a security vulnerability, please follow responsible disclosure guidelines.

**Please do NOT disclose security vulnerabilities publicly through GitHub Issues, pull requests, or discussions.**

### How to Report Privately:
To report a security vulnerability privately, please use **GitHub Private Vulnerability Reporting**:

1. Navigate to the **Security** tab of this repository on GitHub.
2. Select **Advisories** on the left menu.
3. Click the **Report a vulnerability** button to submit a confidential advisory directly to the repository maintainer.

> [!NOTE]
> Private Vulnerability Reporting will be enabled in the repository settings (**Settings > Code security and analysis > Private vulnerability reporting**) upon public release. If the reporting button is unavailable, please open a standard repository discussion requesting private security contact without disclosing vulnerability details.

### When submitting a report, please include:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. The affected endpoint, module, or configuration setting.
4. Any proposed remediations or patches, if available.

### What to expect:
* **Acknowledgment:** Receipt of your vulnerability report will be acknowledged within **48 hours**.
* **Assessment & Fix:** We will evaluate the report, verify the issue, and prepare a patch in a timely manner.
* **Coordination:** Public disclosure will be coordinated once the remediation has been deployed.

Thank you for helping keep Bilge AI and its users secure.
